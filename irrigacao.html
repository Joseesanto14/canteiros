Irrigação

Sistema de Irrigação

Descrição: O sistema de irrigação automatizado foi desenvolvido para garantir que as plantas recebam a quantidade ideal de água, economizando recursos e otimizando o crescimento. Este sistema utiliza sensores de umidade do solo para acionar a irrigação apenas quando necessário, evitando o desperdício de água e garantindo a saúde das plantas.

Componentes: O sistema é composto por sensores de umidade, uma placa controladora, válvulas solenoides e um sistema de gotejamento.

Vantagens: Redução do consumo de água, crescimento mais saudável das plantas, e menor necessidade de intervenção manual.
